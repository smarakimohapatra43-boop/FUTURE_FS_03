# Debraj Kalyan Mandap Website

A professional local business website developed for Debraj Kalyan Mandap to provide online booking, customer enquiries, and business visibility through a modern responsive web application.

---

## 🌐 Live Demo
https://future-fs-03-1-rsuu.onrender.com

---

## 📌 Project Overview

This project was created to help a local marriage/event venue establish an online presence and improve customer interaction through digital services.

The website allows customers to:
- View venue details
- Explore image galleries
- Send enquiries
- Book events online
- Contact directly through WhatsApp

---

## ✨ Features

- ✅ Online Booking Form
- ✅ WhatsApp Enquiry Integration
- ✅ Responsive Design
- ✅ Image Slider / Gallery
- ✅ Google Maps Location Integration
- ✅ MongoDB Database Storage
- ✅ Modern User Interface
